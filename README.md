## VidyGuideAI

### The AI career platform — live, evolving, built with real users.

<a href="https://vidyguide.is-a.dev"><img src="https://raw.githubusercontent.com/sanginenivamshi21-hub/VidyGuideAI/main/assets/screenshots/dashboard.jpg" alt="VidyGuideAI dashboard" width="100%" /></a>

An AI-powered career companion: an AI mentor that remembers your background, an ATS-optimized resume builder with OCR parsing, resume review, career roadmaps, and interview prep — in 10+ Indian languages. Deployed, documented, and maintained like a product, not a college project. **Status: actively developed MVP with a long-term product vision.**

| Surface | What it does |
|---|---|
| **AI Mentor** | Streaming conversation (SSE) · LLaMA 3 on Groq with automatic Gemini/OpenRouter fallback · persistent user context · file + voice input |
| **Resume Builder & Review** | 5 ATS templates · OCR scan · one-click ATS scoring with AI feedback · PDF export |
| **Interview Prep** | Mock interviews with role-specific questions and scored feedback |

**Built with:** Next.js 15 · NestJS 11 · PostgreSQL 16 · Prisma · React 19 · Tailwind 4 · Docker · GitHub Actions · pnpm monorepo · Conventional Commits · MIT.

**Engineering decisions** (each documented in the repo): provider-factory AI fallback · JWT in http-only cookies · SSE over polling for token streaming · the deliberate migration from a Streamlit/FastAPI prototype to a type-safe monorepo.

**Next:** skill-gap analysis · company-specific question banks · LinkedIn integration.

---

## Engineering Manifesto

1. **Build products, not demonstrations.** Working software with users is the only proof that matters.
2. **Evidence over claims.** Every skill on this page traces to a repository, a certificate, or an internship.
3. **Document the decisions, not just the code.** Why is worth more than what.
4. **Security by default.** Http-only cookies, validation, rate limiting, gitignored secrets — from the first commit, not the last.
5. **Consistency compounds.** Daily DSA commits and Conventional Commits over occasional heroics.
6. **AI is a capability, not an identity.** It is a tool I integrate deliberately, never a title.
7. **Every engineering decision should feel intentional.** If I can't explain a choice, I make a better one.
